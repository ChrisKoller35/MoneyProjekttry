# Spiele

Ein Ordner pro Spiel. Jedes Spiel:

- läuft als einzelne `index.html` im Browser (Handy mit Finger, PC mit Maus), ohne Internet, unter 5 MB
- kommt ohne Sprache aus (Symbole statt Text), Grafik aus Code
- speichert Highscore oder Fortschritt im Browser
- bindet Werbung nur über die Schnittstelle des Portals ein (Platzhalter, bis das Spiel eingereicht wird)
- hat einen `README.md` mit Spielregel, Beschreibung Deutsch/Englisch und Stand

Reihenfolge laut `../PLAN.md`: C Turmstapler, dann A Zwergen-Mine, dann nach Zahlen.
