# Moneyprojekt

Seit 18.10.2026: **kleine Browser-Spiele für Spieleportale** (CrazyGames und weitere). Die Portale zeigen Werbung im Spiel und zahlen dem Hersteller einen Anteil.

- `PLAN.md` – Regeln, Spielideen, Meilensteine
- `NEUSTART-VORSCHLAEGE.md` – warum dieser Weg (Vorschläge vom 18.10.2026)
- `spiele/` – ein Ordner pro Spiel, jedes Spiel läuft als einzelne HTML-Datei im Browser
- `archiv/` – frühere Linien (Kurzgeschichten, Pino-Kindergeschichten), werden nicht weiterverfolgt
